# Feature status

[Baseline](BASELINE.md) defines intent. This table describes implemented code; validation results belong in the cleanup handoff, not inferred from design plans.

| Area | Baseline | Remaining work |
|---|---|---|
| World | Seeded home and woodland, loading transitions, persisted generator settings | More biomes and procedural dungeons |
| Player | Third-person camera, keyboard/mouse and gamepad actions, dodge | Mac feel tuning |
| Combat | Melee, shield, crossbow and staff; readable prototype enemies | Final animation and encounter tuning |
| Crafting/building | Regional structures and storage, terrain-aware placement, modular kit | More recipes/content, final visuals |
| Camps | Protection, cooking, discovery, recovery, dynamic travel | Balance and standalone review |
| Persistence | Separate Characters, Worlds and Visits; fresh versioned baseline | Future schema migrations when needed |
| Survival | Benefit-only stamina, food and rest, world clock/weather | Balance and presentation |
| Art/UI | Terrain sample, neutral characters/props, existing Journal | Replacement character/building art |

The source audio library and unfinished audio curation remain intact. No individual visual-asset approval workflow remains.
