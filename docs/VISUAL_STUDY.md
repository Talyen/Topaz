# URP Visual Lab

The Bootstrap Mac build contains a reversible visual study for the KayKit art. Open **Options → Visual Lab** from the title or Esc pause menu, or press **F7** during play. F5 cycles Lighting only, Painterly, and Focus preview; F6 cycles anti-aliasing Off, FXAA, SMAA, and TAA. These are review controls, not final game settings.

The menu changes 14 values live: color temperature, exposure, contrast, saturation, bloom strength and threshold, vignette, depth-of-field start/end/radius, fog end distance, home light intensity, shadow strength, and the extra warmth near home. Focus start/end stay ordered when either slider moves. The Look, AA, and Depth of field buttons provide the same comparisons as the shortcuts. **Reset** restores authored study values. **Save selection** writes `visual-study-settings.json` in Unity's persistent data directory and reloads it on the next Mac launch; it is separate from the gameplay save. **Copy values** places that JSON on the clipboard. Editor tests use isolated temporary settings paths.

## Current review defaults

The owner chose a warmer look: color temperature **40**, exposure **0**, contrast **0**, saturation **10**, bloom strength **1.00** with threshold **0.70**, vignette **0**, home light **10**, home warmth **35**, shadow strength **0.90**, **TAA**, and depth of field **on**. These are study defaults, not established performance targets. Biomes may later have separate color temperature and atmosphere profiles.

For Gaussian depth of field, **Start 25** means distant pixels begin to blur at 25 world units from the camera, **End 32** means the blur reaches its maximum at 32, and **Radius 1.0** sets that maximum blur size. In the current balanced camera, the player is about 22 units away and the visible ground spans roughly 14–33 units. This keeps the player clear while softening the far edge. Unity warns that radius values above 1 can produce undersampling artifacts. [Depth-of-field reference](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/depth-of-field-volume-override-reference.html)

The scene uses linear fog beginning at **26** world units. **Fog End 65** means the fog color would be fully applied at 65; a smaller end value strengthens haze in the visible far field, while a larger one weakens it. It is intentionally subtle at the current camera scale. [Unity fog start](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/RenderSettings-fogStartDistance.html) · [fog end](https://docs.unity3d.com/6000.6/Documentation/ScriptReference/RenderSettings-fogEndDistance.html)

## Native Unity setup

- The [URP Volume framework](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/volumes-landing-page.html) uses `Painterly Clear` globally, `Warm Home` locally with the player as the camera's volume trigger, and a `Focus Preview` overlay. Authored profiles live under `Assets/Topaz/VisualStudy/Profiles/`; the player clones them before live slider changes.
- The default grade uses Neutral tonemapping to retain KayKit's gradient-atlas colors, the chosen warm color values, bloom, and Gaussian depth of field. [Bloom reference](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/post-processing-bloom.html)
- The camera defaults to the owner's selected TAA. It can ghost on motion, so compare it with SMAA in the player. MSAA stays disabled during this comparison; URP documents that TAA cannot be combined with MSAA. [Unity 6.6 URP anti-aliasing](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/anti-aliasing.html)
- A cool real-time directional light supplies soft shadows; one unshadowed warm point light and a local Volume distinguish the homestead. The shadow distance is 32 world units with two cascades. A KayKit lantern has an emissive ember and a bounded built-in Particle System. No custom renderer or effects package was added. [Unity lighting](https://docs.unity3d.com/6000.6/Documentation/Manual/LightingOverview.html)
- The review build disables URP's **Strip Unused Post Processing Variants** setting. A headless build classified Gaussian depth of field as inactive and removed its shader, so slider changes had no visible effect. Unity documents this setting as assuming that runtime Volume profiles do not introduce new effects; Topaz clones and changes Volume profiles for the Visual Lab. Re-evaluate targeted stripping when the final effect set is fixed. [URP graphics settings](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/urp-global-settings.html)

The scene remains a small art audition. Judge each setting in motion at 60 Hz on Mac, including aim, dodge, combat tells, and foliage edges. Formal Windows 1080p/120 FPS conclusions require a representative standalone scene on the designated PC. See [performance process](PERFORMANCE.md).
