# URP Visual Lab

The Bootstrap Mac build contains a reversible visual study for the KayKit art. Open **Options → Visual Lab** from the title or Esc pause menu, or press **F7** during play. F5 cycles Lighting only, Painterly, and Focus preview; F6 cycles anti-aliasing Off, FXAA, SMAA, and TAA. These are review controls, not final game settings.

The menu changes 14 values live: color temperature, exposure, contrast, saturation, bloom strength and threshold, vignette, depth-of-field start/end/radius, fog end distance, home light intensity, shadow strength, and the extra warmth near home. Focus start/end stay ordered when either slider moves. The Look, AA, and Depth of field buttons provide the same comparisons as the shortcuts. **Reset** restores authored study values. **Save selection** writes `visual-study-settings.json` in Unity's persistent data directory and reloads it on the next Mac launch; it is separate from the gameplay save. **Copy values** places that JSON on the clipboard. When the owner chooses defaults, an agent can read the saved file on this Mac or the pasted JSON and author the selected values into the project. Editor tests use isolated temporary settings paths.

## Native Unity setup

- The [URP Volume framework](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/volumes-landing-page.html) uses `Painterly Clear` globally, `Warm Home` locally with the player as the camera's volume trigger, and a `Focus Preview` overlay. Authored profiles live under `Assets/Topaz/VisualStudy/Profiles/`; the player clones them before live slider changes.
- The default grade uses Neutral tonemapping to retain KayKit's gradient-atlas colors, small color adjustments, modest bloom, and a light vignette. Focus preview adds **Gaussian** depth of field. Unity documents Gaussian as the faster, more limited option; keep the character and combat space readable when tuning the focus distances. [Depth-of-field reference](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/depth-of-field-volume-override-reference.html) · [Bloom reference](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/post-processing-bloom.html)
- The camera defaults to SMAA for sharp edges with no temporal history. FXAA is a lighter comparison; TAA is available to inspect but may ghost on motion. MSAA stays disabled during this comparison, and URP documents that TAA cannot be combined with MSAA. [Unity 6.6 URP anti-aliasing](https://docs.unity3d.com/6000.6/Documentation/Manual/urp/anti-aliasing.html)
- A cool real-time directional light supplies soft shadows; one unshadowed warm point light and a local Volume distinguish the homestead. The shadow distance is 32 world units with two cascades. A KayKit lantern has an emissive ember and a bounded built-in Particle System. No custom renderer or effects package was added. [Unity lighting](https://docs.unity3d.com/6000.6/Documentation/Manual/LightingOverview.html)

The scene remains a small art audition. Judge each setting in motion at 60 Hz on Mac, including aim, dodge, combat tells, and foliage edges. Formal Windows 1080p/120 FPS conclusions require a representative standalone scene on the designated PC. See [performance process](PERFORMANCE.md).
