# Roadmap

1. Validate the cleaned [baseline](BASELINE.md) in desktop builds and tune third-person movement, building and camps.
2. Replace neutral character/equipment/building visuals with coherent higher-fidelity fantasy art.
3. Broaden procedural outdoor content and encounters; add a first procedural dungeon.
4. Expand crafting/progression content after the core loop is enjoyable.
5. Measure a representative slice on the designated Windows hardware before establishing performance budgets.

No seamless streaming, terrain editing, structural physics, raids, multiplayer, or asset-by-asset approval process is committed for this baseline.
