# Finding 3D art for Topaz

Research checked on **2026-09-23**. This is a sourcing shortlist, not an import record or a final art direction. KayKit free packs were subsequently imported; see the [KayKit art study](studies/KAYKIT_ART_STUDY.md) and [third-party asset register](THIRD_PARTY_ASSETS.md) for the exact files and licenses. The project is public and may become a commercial game, so an asset must permit **commercial use and public redistribution of the actual source files committed to this repository**. Keep imported art under its own license; [Topaz's rights notice](../RIGHTS.md) does not turn third-party art into Topaz-owned art.

## Sources that need per-asset review

| Source | Use it for | Check before a public commit |
| --- | --- | --- |
| [itch.io CC0 asset search](https://itch.io/game-assets/assets-cc0/free) | Finding an individual missing prop or another single-creator collection. | Search filters are discovery tools, not license evidence. Open the creator's pack page and included license; verify the **free** file set and current terms. |
| [OpenGameArt](https://opengameart.org/) | Specific gaps when the primary packs cannot supply them. | Its [FAQ](https://opengameart.org/content/faq) describes several licenses. Favor an exact CC0 asset; CC BY can work with complete credits and license notices. Avoid assuming a collection has one license or a consistent art style. |
| [Poly Pizza](https://poly.pizza/) and [Sketchfab free downloads](https://sketchfab.com/search?features=downloadable&type=models) | A hard-to-find model after the pack search. | They host work from many creators. Poly Pizza's [terms](https://poly.pizza/docs/tos) say to follow the license on each model; Sketchfab supports both [Creative Commons and other licenses](https://sketchfab.com/blogs/community/restricting-generative-ai-use-of-free-models/). Verify the exact model, creator, download rights, source redistribution, and attribution. |
| [Unity Asset Store](https://assetstore.unity.com/) and [Unity sample projects](https://assetstore.unity.com/packages/templates/packs/3d-game-kit-3d-sample-project-115747) | Learning, local visual comparison, and gameplay/authoring examples. | A zero price does **not** grant permission to expose raw files in a public Git repo. Unity's [Asset Store FAQ](https://assetstore.unity.com/browse/eula-faq) permits distribution only when assets are embedded in a substantial licensed product. Some Unity-authored samples use the [Unity Companion License](https://unity.com/legal/licenses/unity-companion-license) or have third-party notices; inspect the exact package before any import. The 3D Game Kit originated on an older Unity version and is large, so treat it as a reference rather than a Topaz art base. |

### Quaternius: attractive art, conflicting license signals

[Quaternius](https://quaternius.com/) has particularly relevant coherent packs: [Stylized Nature MegaKit](https://quaternius.com/packs/stylizednaturemegakit.html), [Medieval Village MegaKit](https://quaternius.com/packs/medievalvillagemegakit.html), [Fantasy Props MegaKit](https://quaternius.com/packs/fantasypropsmegakit.html), [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html), and [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html). Free downloads usually provide only part of a MegaKit; ready-made Unity projects, custom shaders, or source files may be in paid editions.

**Do not commit a newly downloaded Quaternius pack to this public repo on the strength of an old CC0 badge alone.** Several pack pages still display CC0, and the [FAQ](https://quaternius.com/faq.html) still says CC0, but the current [Quaternius Asset License (QAL), updated 2026-08-28](https://quaternius.com/license.html), forbids redistributing the assets themselves as assets. An openly accessible Unity project exposes the raw model and texture files, so the sitewide QAL is not a clear fit for Topaz's repository. The QAL says it does not retroactively change earlier grants; that matters only if we can document an exact pack and license obtained earlier. For any future use, resolve the conflicting notices for the exact download with the creator or obtain explicit public-source redistribution permission, then preserve that evidence in the asset register. The [2026 Bestiary kit](https://quaternius.com/packs/bestiarydungeonmonsterskit.html) visibly uses QAL, so Quaternius cannot be treated as uniformly CC0.

## A style audition before choosing a pack family

Compare **one primary creator at a time** in a temporary, reviewable Mac scene: one player, one enemy, trees and rocks, a home wall/roof, chest/workbench, axe/sword, and one dungeon corner. Use Topaz's fixed orthographic camera, normal zoom range, URP lighting, and 60 Hz Mac playtest. The first candidates are KayKit alone and Kenney alone. Quaternius can be compared visually, but its files stay outside the public project while the license conflict is unresolved.

Judge the scene at gameplay size: clear silhouettes and attack tells, consistent proportions, coherent palette/material roughness, readable ground contrast, useful animation rigs, modular seams, sensible scale, and acceptable import/build cost. A pack that looks good in close-up marketing images can fail in a fixed-angle view. Record the chosen family, rejected alternatives, and a screenshot or Mac build in the relevant feature document. Use shared URP materials, lighting, color grading, and a limited palette to align a few gap fillers; do not assume unrelated low-poly packs will match automatically.

## Repeatable agent workflow for an asset request

1. Search the chosen pack family for the needed asset and its matching neighboring assets. Prefer one creator/pack across a visible area. If it is missing, check another proven CC0 source before broad marketplaces.
2. Inspect the **exact** free download page and archive license. Confirm commercial use, modification, public source redistribution, attribution, and any third-party textures/fonts. Save the URL, date, pack version or revision, and original archive SHA-256. If the evidence conflicts or is unclear, do not import it to the public repo.
3. Stage the pack outside `Assets/` and select only the files Topaz uses. Unity's [6.6 model format reference](https://docs.unity.com/en-us/engine/6000.6/manual/assets-and-media/asset-types/models/creating-dccassets/3d-formats) lists FBX and OBJ; use those from free packs unless the project deliberately adds another importer. Check units, axis, materials, rigs, animation clips, and textures through the [model import workflow](https://docs.unity.com/en-us/engine/6000.6/manual/assets-and-media/asset-types/models/importing/importing-model-files).
4. Let Unity import the selected files and create a small prefab with URP materials, collider, navigation settings, and stable references. Keep every `.meta`. Record source files, license copy, changes, and runtime paths in [the register](THIRD_PARTY_ASSETS.md). Do not redistribute an entire upstream pack just because it is convenient.
5. Review a screenshot or Mac build at the actual game camera and run the normal project verification for any imported asset or scene change. Measure performance only in a representative scene, following [PERFORMANCE.md](PERFORMANCE.md).

## Generation and authoring options

- **Reuse and vary licensed kit pieces first.** Editor scripts can assemble authored scene variants or remap a shared URP palette without creating dozens of unrelated models. Keep region layouts hand-authored, as [ARCHITECTURE.md](ARCHITECTURE.md) specifies. This is the most promising automation path for consistency.
- **Unity ProBuilder** is a [released Unity 6.6 package](https://docs.unity3d.com/6000.6/Documentation/Manual/com.unity.probuilder.html) for blockouts, simple custom geometry, and collision meshes. It is useful when a modular gap prevents playtesting; it does not supply a finished RPG asset library and is not currently installed.
- **Blender Geometry Nodes and Python** can make controlled variants of legally reusable source meshes, with [Geometry Nodes](https://docs.blender.org/manual/en/5.3/modeling/geometry_nodes/introduction.html) and [FBX export scripting](https://docs.blender.org/api/current/bpy.ops.export_scene.html). A deterministic script plus one pack's palette is more repeatable than unrelated text-to-3D prompts, but this adds an art pipeline to maintain. Use only if the pack audition exposes a recurring gap.
- **Unity AI 3D Object Generator** can [create a prefab from text or an image](https://docs.unity3d.com/Packages/com.unity.ai.assistant@2.3/manual/3d-terrain/3d-generator-overview.html). Its documented outputs are simple single-part props without rigs or animations. It is a preview, cloud-linked, [credit-based](https://unity.com/legal/unity-ai-credits-terms) path with [third-party model terms](https://unity.com/legal/third-party-ai-terms); a [free trial allowance](https://unity.com/onboardingsuccess/unity-ai) is finite. Treat it as a one-off prototype experiment, not a guaranteed zero-cost, stylistically coherent production library. Review output geometry, textures, performance, and rights before any public commit.

No option found removes the need to choose an art direction and inspect results in the actual game view. The practical zero-cost starting point is a KayKit-only scene, with Kenney as a second complete look or carefully reviewed supplement.

For animation, effects, lighting, physics, anti-aliasing, and weather, see the [Unity capability map](UNITY_FEATURE_POLICY.md#engine-capabilities-versus-content). It separates systems Unity supplies from rigged models, clips, sounds, and authored visual settings.
