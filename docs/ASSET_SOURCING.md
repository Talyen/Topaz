# Asset sourcing

Prefer Synty POLYGON assets for natural-fantasy environments, characters and props. Start with the owned Starter Pack; use matching owned placeholders for gaps and purchase no additional packs without owner direction. No per-asset approval gallery is required. Review coherent sets in a playable build when visual judgment is needed.

Before importing an asset, verify its exact license and public source redistribution terms. Publicly committed source assets must permit that redistribution; otherwise keep the source ignored and provide an acquisition/restore manifest. Record provenance, license, attribution and imported files in THIRD_PARTY_ASSETS.md. Preserve original downloads and all audio review work. Do not acquire new packs as part of the baseline cleanup.
