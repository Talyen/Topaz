# Asset sourcing

Prefer Synty POLYGON assets for natural-fantasy environments, characters and props. The full owned Synty library is authorized for use, including assets not yet wired into gameplay. Viking Realm and Alpine Mountain remain style anchors for the starting biome; choose compatible architecture, vegetation, rock forms, props and effects from every owned pack to build coherent fantasy compositions. Purchase no additional packs without owner direction. No per-asset approval gallery is required. Existing imported libraries are the normal authoring source; do not restore/reimport packs or rerun setup commands for ordinary iteration. Review coherent sets in a playable build when visual judgment is needed.

Before importing an asset, verify its exact license and public source redistribution terms. Publicly committed source assets must permit that redistribution; otherwise keep the source ignored and provide an acquisition/restore manifest. Record provenance, license, attribution and imported files in THIRD_PARTY_ASSETS.md. Preserve original downloads and all audio review work. Use the current [restoration instructions](THIRD_PARTY_ASSETS.md#restoring-current-private-dependencies) for existing dependencies; [audio policy](AUDIO_ASSET_POLICY.md) governs active sound assets.
